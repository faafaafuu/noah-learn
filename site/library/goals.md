# Цели

Цели живут на сроках **год → месяц → неделя → сегодня**, и большая цель тянет маленькие: задача дня привязана к цели недели, неделя — к месяцу.

## Какие бывают

| Вид | Пример |
|---|---|
| урок темы | «Урок: остаточный член Лагранжа» |
| наизусть | «Тейлор: все понятия наизусть» |
| проверка темы | «Сдать экзамен темы» |
| практика темы | «Практика по теме в терминале» |
| собеседование | «Устный экзамен разговором» |
| повторить карточки | «Повторить 24 карточки» |
| фокус, минут | «Фокус 25 минут» |
| пройти тем | «3 темы за месяц» |
| пройти курс целиком | «Сдать матанализ на „отлично“» |
| своё по курсу | любая формулировка |

## Отмечаются сами

Урок прочитан, экзамен сдан, карточки повторены, минуты фокуса набраны — цель закрывается без галочек руками.

## Ноа планирует

Скажи, чего хочешь и к какому сроку, — Ноа разложит по темам курса и твоему темпу. Каждое утро она предлагает задачи на сегодня. Цели может ставить и твоя нейросеть через [MCP](#/library/mcp).

Цели синхронизируются между устройствами; удалённая цель не воскресает при синхронизации.
