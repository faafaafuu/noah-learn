# Устройство

```
 браузер ──┐
 iPhone ───┼── сервер Qrack ──┬── модель (твоя или по умолчанию)
 Windows ──┘   курсы, прогресс,└── голос: озвучка и распознавание
               цели, сборки
```

## Клиенты

Все три — **одни и те же экраны** (`src/learn.html`, `src/js/learn-app/`): одна логика, одни настройки.

- **Браузер** — команды, которые на устройстве выполняет программа, здесь выполняет страница (`src/js/web/web-api.js`), движок учёбы — `learn-core.js`.
- **iPhone** — сборка Tauri с движком учёбы на Rust.
- **Windows** — та же сборка Tauri с признаком `qrack`: отдельная программа, окно с экранами Qrack, Ноа-ассистент, голос и терминал.

## Движок учёбы

Интервальное повторение, проверка ответов, экзамены, прогресс — один движок: `src-tauri/src/learning.rs`, `recall.rs`, `srs.rs` в программе и его повтор в `learn-core.js` для браузера, с общими тестами.

## Сервер

Node без фреймворков, SQLite. Курсы, прогресс и цели, сборка курсов, голос, MCP. Сборки идут на сервере: устройству не нужно держать соединение, а обрыв связи не рвёт сборку посередине.
