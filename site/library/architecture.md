# Устройство

```
 онлайн ────┐
 мобильный ─┼── сервер Qrack ──┬── модель (твоя)
 ПК ────────┘   курсы, прогресс,└── голос: озвучка и распознавание
               цели, сборки
```

## Клиенты

Логика, движок учёбы и настройки — **одни на всех**; экраны мобильного и онлайн общие, у программы на ПК — свой вид окна (`src/learn.html`, `src/js/learn-app/`): одна логика, одни настройки.

- **Онлайн** — команды, которые на устройстве выполняет программа, здесь выполняет страница (`src/js/web/web-api.js`), движок учёбы — `learn-core.js`.
- **Мобильный** (iPhone, Android) — сборка Tauri с движком учёбы на Rust.
- **ПК** (Windows, macOS, Linux) — та же сборка Tauri с признаком `qrack`: отдельная программа со своим видом окна — заголовок, боковое меню, курсы сеткой, — Ноа-ассистент, голос и терминал.

## Движок учёбы

Интервальное повторение, проверка ответов, экзамены, прогресс — один движок: `src-tauri/src/learning.rs`, `recall.rs`, `srs.rs` в программе и его повтор в `learn-core.js` для браузера, с общими тестами.

## Сервер

Node без фреймворков, SQLite. Курсы, прогресс и цели, сборка курсов, голос, MCP. Сборки идут на сервере: устройству не нужно держать соединение, а обрыв связи не рвёт сборку посередине.
