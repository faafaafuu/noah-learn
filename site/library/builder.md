# Сборка курса

Курс собирается в приложении на модели из [настроек](#/library/models). Сборщик один для всех устройств — `src/js/web/course-builder.js`:

1. **План** — темы и порядок по цели и сроку.
2. **Урок темы** — разделами, по стандарту.
3. **Понятия и карточки.**
4. **Задачи и экзамен.**
5. **Проверка** по [стандарту курса](#/library/format) — не прошла, модель исправляет.
6. **Сохранение после каждой темы** — учиться можно с первой.

Урок следующей темы пишется, пока составляются вопросы текущей.

## Надёжность

- Готовые темы сохраняются в аккаунт сразу — обрыв связи не теряет сделанное, сборку можно продолжить.
- **Стоп** останавливает сразу: текущий запрос к модели прерывается.
- Временный сбой — повтор; ключ заблокирован или лимит исчерпан — сразу понятная ошибка, без бесконечных повторов.
