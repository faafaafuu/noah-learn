# Что такое Qrack

Qrack — приложение для учёбы с ИИ-наставником Ноа. Ты говоришь цель своими словами — «матанализ к сессии, нужны доказательства для устного» или «собеседование на системного аналитика через месяц», — и Ноа собирает курс тема за темой, объясняет голосом, гоняет до «наизусть», принимает экзамен разговором и ставит цели на день, неделю, месяц и год.

## Где работает

| | |
|---|---|
| **Онлайн** | `noahlab.ru/qrack/app/` — уже сейчас, ничего ставить не нужно. |
| **ПК** | Windows, macOS и Linux — отдельная программа с Ноа-ассистентом внутри, скоро. Посмотреть — на странице [«Попробовать»](#/try/pc). |
| **Мобильный** | iPhone и Android — скоро. |

Курсы, прогресс и цели — в аккаунте и общие на всех устройствах: начал тему на компьютере, продолжил с телефона.

## Круг учёбы

Каждая тема проходит один и тот же круг — так материал не вылетает из головы:

1. **Урок** разделами: после каждого раздела нужно вспомнить одно понятие без подсказки.
2. **Наизусть** — понятия порциями по шесть: прочитал, восстановил по пропускам, пересказал.
3. **Задачи и практика** — в том числе в настоящем терминале.
4. **Экзамен темы** и **устный экзамен** разговором.
5. **Повторение** карточек по интервальному расписанию — ровно тогда, когда начинаешь забывать.

Курс пройден не когда всё прочитано, а когда всё держится уверенно — три недели и дольше.
