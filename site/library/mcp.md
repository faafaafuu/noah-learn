# MCP: курсы из твоей нейросети

Курсы собираются в самом Qrack. MCP — дополнение для тех, кто и так работает в Claude, ChatGPT или Cursor: подключи Qrack как коннектор, и нейросеть из твоего чата добавит тему, поправит курс или поставит цели прямо в аккаунте.

## Подключение

Адрес коннектора:

```
https://noahlab.ru/qrack/mcp
```

Добавь его в настройках коннекторов своего клиента — откроется вход в Qrack (OAuth). Нейросеть получит доступ только к курсам и целям.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `course_format` | стандарт и методика курса — нейросеть читает его первым |
| `create_course` | создать или заменить курс; ответ — отчёт проверки |
| `add_topic` | добавить тему или заменить тему с тем же id |
| `remove_topic` | убрать тему |
| `list_courses` | курсы в аккаунте |
| `get_course`, `get_topic` | прочитать курс или тему целиком |
| `list_goals` | цели и прогресс по ним |
| `add_goal`, `update_goal`, `remove_goal` | поставить, поправить, убрать цель |

## Что можно попросить

- «Собери курс по сопромату по моей методичке» — и приложи файл.
- «Добавь в матанализ тему про ряды Фурье».
- «Поставь цели до сессии 20 января».
- «Что я сделал за неделю?»

Каждый курс проходит ту же проверку, что и собранный в приложении: нейросеть получает отчёт и исправляет ошибки сама.
