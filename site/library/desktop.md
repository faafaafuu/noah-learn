# Программа для компьютера

Qrack для Windows, macOS и Linux — **отдельная программа**, а не модуль помощника NOAH. Те же экраны и настройки, что в мобильном и онлайн, но разложены для большого экрана: меню слева, экран шире, окна выбора — по центру. Сузить окно — станет как на телефоне. Онлайн-версия в браузере на компьютере выглядит так же. Плюс то, что умеет только компьютер:

- **Ноа-ассистент** — спроси голосом или текстом о чём угодно по курсу.
- **Терминал в окне** — практика по сценарию прямо на твоём компьютере.
- **Голос** — распознавание речи и озвучка уроков.

Модель, ключи, вход и синхронизация — как в [настройках](#/library/models) приложения. Курсы и цели общие с телефоном и браузером.

Программа готовится к выпуску. Как она выглядит — на странице [«Попробовать»](#/try/pc).

## Сборка

Та же программа Tauri, что и помощник NOAH, с признаком `qrack`:

```bash
npm run tauri build -- --features qrack --config src-tauri/tauri.qrack.conf.json
```

На Windows получается установщик `Qrack_<версия>_x64-setup.exe` — ставится для текущего пользователя, без прав администратора; на macOS и Linux — свои пакеты той же сборки.
