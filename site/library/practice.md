# Практика в терминале

Для технических курсов — практика в настоящем терминале. Ноа ведёт по сценарию темы: даёт шаг, **видит вывод команд**, подсказывает, если что-то пошло не так, и переходит дальше, когда шаг выполнен.

- На компьютере — терминал прямо в окне Qrack.
- На телефоне — подключение по SSH к своему серверу.
- Опасные команды Ноа не даст запустить без предупреждения.
