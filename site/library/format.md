# Стандарт курса

Курс — не конспект. Конспект отвечает на вопрос «где это написано», курс — «смогу ли я это сказать через месяц без подглядывания». Каждая часть курса нужна для одного шага круга: урок → вспоминание → задачи → экзамен → повторение.

## Курс

```json
{
  "id": "matan",
  "title": "Матанализ к сессии",
  "aliases": ["матан", "матанализ"],
  "description": "Для кого и что внутри — два предложения.",
  "final": [ "сквозные вопросы на стык тем" ],
  "topics": [ "тема", "тема" ]
}
```

## Тема

| Поле | Что это |
|---|---|
| `lesson` | урок в Markdown: 3–7 разделов `## …`, в каждом одна мысль |
| `concepts` | 6–15 понятий |
| `cards` | свои карточки сверх понятий: сравнения, порядок шагов, числа |
| `tasks` | 3–5 практических задач |
| `exam` | 6–10 вопросов, не меньше половины — своими словами |

## Понятие

```json
{
  "id": "lagrange",
  "term": "Остаточный член в форме Лагранжа",
  "definition": "Ошибка многочлена Тейлора: f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (x−a)ⁿ⁺¹ для некоторой точки ξ между a и x.",
  "mnemonic": "Следующий член ряда, только производная взята «где-то посередине».",
  "analogy": "Сдача после покупки: сколько не хватило до точной суммы.",
  "example": "eˣ на [0; 1], n = 3: ошибка не больше e/24 ≈ 0,11.",
  "pitfall": "ξ зависит от x — это не константа, её нельзя вынести за знак предела.",
  "related": ["taylor", "limits/lhopital"]
}
```

- **definition** — одна мысль, до 320 знаков: вспомнить можно только короткое.
- **mnemonic** и **analogy** — хотя бы у половины понятий.
- **related** — 2–4 связи, в том числе с другими темами: из них строится карта курса.

## Что проверяется

**Не примет:** урок меньше трёх разделов; меньше 6 понятий; определение длиннее 320 знаков; связь в несуществующее понятие; повторяющиеся id; вопрос с вариантами без верного ответа; открытый вопрос без ключевых пунктов и образцового ответа.

**Примет, но подскажет:** урок короче 1200 слов; понятия, названные в уроке, но не объяснённые; мало зацепок и частых ошибок; меньше двух связей с другими темами.

Этот же стандарт видит нейросеть, подключённая по [MCP](#/library/mcp), — инструмент `course_format`.
