# Что использовать

Каждую часть учёбы можно включить или выключить — выключенное пропадает из экранов темы и урока.

- **При сборке курса** — «Что будет в курсе»: переключатели сами подстраиваются под тему (для матанализа терминал выключен, для DevOps — включён), любой можно поменять.
- **У готового курса** — Обзор курса → «Ещё» → «Что в курсе».
- **Для всех курсов сразу** — «Что использовать в учёбе» на главной.

| Часть | Что даёт |
|---|---|
| **Ролики-схемы** | короткое видео по теме и разделу урока |
| **Аудиодрамы** | история по уроку на три голоса и вопросы после неё |
| **Собеседование** | Ноа задаёт вопросы вслух и разбирает ответы |
| **Команды для практики** | в конце урока — что набрать в терминале и что делает каждая команда |
| **Практика в терминале** | задача по теме, Ноа ведёт по шагам |
| **Карточки** | повторение понятий по расписанию |
| **Конспект** | вся тема на одной странице |
