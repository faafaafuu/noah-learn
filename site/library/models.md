# Модель и ключи

Всё в Qrack — сборка курсов, объяснения Суфлёра, разговоры, проверка ответов, собеседование — работает на модели, которую ты выбираешь в **Профиль → Модель**. Настройки те же, что в Ноа. Модели, на которых она уже работала, переключаются одним касанием; новая подключается по ключу.

| Сервис | Что нужно |
|---|---|
| **Ollama** | на ПК: установленная Ollama и скачанная модель — без ключа, без интернета, бесплатно |
| **Claude** | ключ Anthropic |
| **OpenRouter** | ключ OpenRouter — сотни моделей, есть бесплатные |
| **Gemini** | ключ Google AI Studio |
| **Groq** | ключ Groq — очень быстрые ответы |
| **Свой сервис** | адрес OpenAI-совместимого API и ключ, если нужен |

После ввода ключа — «Проверить»: Ноа отправит короткий запрос и скажет, работает ли.

## Где хранится ключ

На устройстве, **в зашифрованном виде**, и уходит только в выбранный сервис. На сервер Qrack ключ не передаётся.
