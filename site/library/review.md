# Повторение по интервалам

Прочитанное забывается по кривой: через день помнится половина, через неделю — почти ничего. Каждое удачное вспоминание делает кривую положе, и следующий раз можно отложить дальше. Поэтому карточку показывают тогда, когда её вот-вот забудут, — не раньше и не позже.

## Как устроено

Расписание — SM-2, тот же метод, что в Anki. У каждой карточки есть интервал и «лёгкость». Оценок четыре:

| Оценка | Что будет |
|---|---|
| **Не вспомнил** | карточка вернётся в этот же сеанс |
| **С трудом** | интервал растёт медленно |
| **Вспомнил** | обычный шаг: 1, 3, 8, 20 дней и дальше |
| **Сразу** | интервал растёт быстрее |

- Новых карточек — до 20 в день, и только из прочитанных тем.
- Ошибка в экзамене возвращает понятие в повторение сегодня же.
- Ответ можно сказать вслух.

## «Уверенно»

Не ощущение, а число: карточка, интервал которой дорос до **трёх недель**, пережила несколько проверок подряд без провала. Курс, где уверенно всё, — это и есть «от зубов отскакивает».
