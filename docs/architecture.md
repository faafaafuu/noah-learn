# Как устроено

```
 браузер ─┐                         ┌─ мост ── Claude Code (модель)
 iPhone ──┼── noahlab.ru (Node) ────┼─ noah-video ── Manim в Docker, голос Silero
 NOAH ────┘   курсы, прогресс,      └─ Википедия (картинки путеводителей)
              сборки, ролики,
              путеводители
```

## Клиенты

- **Браузер** — `noahlab.ru/learn/app/`: те же экраны, что на iPhone. Команды,
  которые на телефоне выполняет программа, здесь выполняет страница
  (`src/js/web/web-api.js`), логика учёбы — `src/js/web/learn-core.js`.
- **iPhone** — «NOAH Учёба»: сборка Tauri с теми же экранами
  (`src/learn.html`, `src/js/learn-app/`) и движком учёбы на Rust.
- **Компьютер** — окно «Обучение» помощника NOAH (`src/learning.html`,
  `src/js/learning.js`): плюс голос, практика в терминале и голосовые команды.

Движок учёбы — интервальное повторение карточек, проверка ответов, экзамены,
прогресс — один: `src-tauri/src/learning.rs`, `recall.rs`, `srs.rs` в
программе и его повтор в `learn-core.js` для браузера (тесты —
`learn-core.test.js`).

## Сервер

`platform/server/` — Node без фреймворков, SQLite (`node:sqlite`).

- `noa.mjs` — курсы, прогресс, сборка курса, голос, мост.
- `remote.mjs` — то же для программы и телефона: курсы кусками, слияние
  прогресса.
- `video.mjs` — ролики: модель пишет сценарий и код, проверка, исправления.
- `guides.mjs` — путеводители: план, разделы, картинки.

Сборки идут на сервере, а не на устройстве: телефону не нужно держать
соединение, а канал из России, который рвёт длинные ответы, не обрывает
сборку посередине.

## Сборка курса

`src/js/web/course-builder.js` — общий для сервера и браузера: план → урок
темы → понятия и карточки → задачи и экзамен → проверка `validate` → курс
сохраняется после каждой темы, учиться можно с первой. Урок следующей темы
пишется, пока составляются вопросы текущей.

## Ролики

1. Модель получает раздел урока и правила (`rules()` в `video.mjs`) и пишет
   заголовок, фразы озвучки по сценам и код на деталях `noah_kit.py` —
   карточки, зоны, стрелки, «пакеты», субтитры.
2. Код проверяется: только `from noah_kit import *`, без файлов и системы,
   `self.hold(i)` по числу фраз. Не прошёл — модель исправляет.
3. Служба `noah-video` (`platform/video/worker.py`) озвучивает сцены, рендерит
   код в контейнере без сети и прав — четырьмя процессами по промежуткам
   озвучки — и сводит звук по фактическим началам сцен. Упал рендер — хвост
   журнала уходит модели на исправление.

Минутный ролик — около двух минут от заказа: сценарий ~40 с, рендер ~70 с.

## Путеводители

План (4–8 разделов) → каждый раздел отдельным вызовом: подводка, абзацы,
цифры, карточки видов, советы, «а вы знали?». К разделам и карточкам —
иллюстрации статей русской Википедии, которые назвала модель. Сохраняется
после каждого раздела. На устройствах — копия для чтения без сети.
